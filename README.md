# 🐍 Snake Arena

A sleek, modern version of the classic Snake game built with **HTML**, **CSS**, and **JavaScript**.  
Eat food to grow, avoid collisions, and chase your high score in a smooth, responsive environment.

## 🎯 Features

- Responsive gameplay with **arrow key controls**  
- Collision detection (walls & self-collision)  
- Dynamic food spawning & snake growth  
- Sound effects on eating and game over  
- Scoreboard with **persistent high score** saved via `localStorage`  
- Smooth animations and modern UI  
- Invisible tail fade (gradient on snake segments)  
- Overlay modal for game over instead of browser `alert`
